# vpn_autoinstall_2026 — VPN-сервер с нуля на Ubuntu 24.04

Один скрипт ставит на чистый сервер **3x-ui** (панель Xray), **wg-easy**
(WireGuard), **Portainer** и опционально **AmneziaWG** — обфусцированный
WireGuard на ядерном модуле, который переживает DPI там, где обычный WireGuard
режут.

Актуализировано 2026-07-26.

## ⚡ Быстрый старт агента

Работать лучше на dev-host — сессии живут на сервере и не привязаны к Mac.

```bash
ssh -t dev-host "cd ~/dev/'Lab + Agents'/projects/vpn_autoinstall_2026 && claude"
```

```bash
ssh -t dev-host "cd ~/dev/'Lab + Agents'/projects/vpn_autoinstall_2026 && codex"
```

- С Mac в GUI: Claude Code → окружение dev-host → эта папка.
- Забрать диалог на телефон: `/remote-control` внутри сессии (работает в терминальной сессии; из Desktop-обёртки пока падает — баг клиента, task 207).

> Установщик — root-level и меняет SSH, UFW, Docker и `/opt`. Локально его не
> запускать; удалённо — только по прямой команде пользователя.

## Установка

На новом сервере от root:

```bash
git clone https://github.com/uroborross/vpn-autoinstall-2025.git /opt/vpn-autoinstall
bash /opt/vpn-autoinstall/install_vpn.sh
```

Имя папки — `vpn_autoinstall_2026`, а публичная репа на GitHub так и осталась
`vpn-autoinstall-2025`; клонировать нужно именно её. Канон — `origin`
(домашний Forgejo), GitHub — публичная копия для установки на серверы.

С AmneziaWG (нужны `linux-headers` для текущего ядра — на стандартной Ubuntu они
уже есть):

```bash
bash /opt/vpn-autoinstall/install_vpn.sh --with-awg
```

## Сразу после установки

SSH переехал на порт `30022`. Старый `22` намеренно остаётся открытым, пока вы
не проверите новый и не закроете его руками:

```bash
ssh -p 30022 root@IP-АДРЕС
ufw delete allow 22/tcp
```

Все параметры и пароли — в `/opt/saved_config` (`cat /opt/saved_config`). Файл
секретный.

## Что снаружи, а что нет

| Сервис | Доступ |
| --- | --- |
| 3x-ui | публично, случайный порт + случайный путь, логин/пароль в `saved_config` |
| wg-easy UDP | публично, `51820/udp` |
| AmneziaWG | публично, `51822/udp` (меняется `--awg-port`) |
| wg-easy панель | **только localhost** — через SSH-туннель |
| Portainer | **только localhost** — через SSH-туннель |

Панели не выставлены наружу намеренно: это админ-доступ к серверу и ко всем
VPN-клиентам. Туннель:

```bash
ssh -p 30022 -L 9000:127.0.0.1:9000 -L 51821:127.0.0.1:51821 root@IP-АДРЕС
```

Дальше Portainer — `http://127.0.0.1:9000`, wg-easy — `http://127.0.0.1:51821`.

## AmneziaWG

Клиентский конфиг создаётся сразу — `/etc/amnezia/amneziawg/client.conf`:

```bash
scp -P 30022 root@IP-АДРЕС:/etc/amnezia/amneziawg/client.conf .
```

Импортируется в приложение AmneziaVPN или в роутер Keenetic (KeeneticOS 5.1+,
«Другие подключения» → загрузить из файла).

Параметры обфускации (`Jc/Jmin/Jmax`, `S1/S2`, `H1–H4`) генерируются случайно и
**обязаны совпадать на обеих сторонах** — поэтому клиентский конфиг берут
готовым, а не собирают руками. Модуль умеет и параметры AmneziaWG 2.0
(`S3/S4`, `I1–I5`), но по умолчанию они выключены ради совместимости с
прошивками, которые их ещё не принимают.

## Опции

| Опция | Назначение |
| --- | --- |
| `--with-awg` | поставить AmneziaWG |
| `--awg-port PORT` | UDP-порт AmneziaWG (по умолчанию 51822) |
| `--ssh-port PORT` | новый SSH-порт (по умолчанию 30022) |
| `--disable-rsyslog` | отключить системное логирование |

Переменные окружения: `PUBLIC_IP`, `XUI_PORT`, `XUI_VERSION`, `WGEASY_VERSION`,
`AWG_SUBNET`.

## Почему версии закреплены

- **3x-ui — на теге** (`XUI_VERSION`, сейчас `v3.5.0`). Плавающий `latest` уже
  ломал установки при смене схемы БД.
- **wg-easy — на мажорной `15`.** В v15 переменной `PASSWORD_HASH` больше нет:
  администратор создаётся при первом входе в панель. Скрипты со старой схемой на
  актуальном образе молча остаются без пароля.
- Настройки 3x-ui задаются штатной `x-ui setting`, а не правкой SQLite по
  числовым id — так установка не ломается при изменении схемы.

## Повторный запуск

Если `/opt/saved_config` уже есть — скрипт ничего не делает и просто сообщает об
этом. Чтобы переустановить, файл нужно удалить осознанно. Этот guard не снимать
без запроса.

## Проверка скрипта

```bash
bash -n install_vpn.sh
shellcheck install_vpn.sh
```

Если `shellcheck` недоступен — хотя бы `bash -n`.
